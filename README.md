# Brouk — Plan de Trabajo Inicial

Plan de conformación de sociedad **Brouk SpA** — documento de trabajo confidencial (Versión 4 · Mayo 2026).

Documento interactivo de una sola página (`index.html`) con 8 secciones navegables por pestañas:

1. **Resumen** — contexto y hitos
2. **Sociedad y socios** — estructura societaria y roles
3. **Gobierno y decisiones** — matriz de responsabilidad y decisiones abiertas
4. **Finanzas y traslado** — diagnóstico financiero y mecanismo de traslado
5. **Presupuestos** — presupuestos autónomos por área
6. **Hoja de ruta** — cronograma Junio → Julio
7. **Migración** — migración de +300 usuarios
8. **Facturación y legal** — corte tributario, banco y pasos legales

## Ver el documento

Abrir `index.html` en cualquier navegador, o ver la versión publicada en GitHub Pages.
